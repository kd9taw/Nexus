# The external symbols the macOS app's static gcc runtimes import: libgfortran.a, libquadmath.a
# and libemutls_w.a from Homebrew's gcc, which crates/tempo-fast-sys/build.rs links into the app.
# Each name here was reviewed against macOS 12 on 2026-10-30, the app's minimum macOS.
#
# scripts/check-macho-bundle.mjs --archive fails the release on any import NOT on this list
# (release.yml runs it on both macOS legs before signing). Objects in those archives are built
# for the runner's macOS (minos 15 on the macos-15 bottles), and that label is not what an older
# Mac refuses: what stops the app at launch is a call into libSystem that macOS 12 lacks.
#
# How the list was made and checked:
#   - The imports were read out of the Homebrew gcc 16.2.0 bottles arm64_sonoma, arm64_sequoia
#     (identical to each other) and the x86_64 sequoia bottle the Intel leg poured on 2026-10-28,
#     counting a symbol one of the three archives defines as no import. The union is below.
#   - Every name is exported by libSystem in the macOS 11.3 SDK (usr/lib/libSystem.B.tbd and
#     usr/lib/system/*.tbd) for the architecture that imports it, so it exists on macOS 12. The
#     newest libSystem APIs among them are getentropy, clock_gettime and mkostemp (10.12).
#   - Except these 21, which libSystem exports on no macOS (checked in the 11.3, 12.3 and 15.5
#     SDKs), so they can never become a dyld lookup: the link resolves them statically, from the
#     compiler runtime (the 128-bit float helpers ___*tf2/___*tf3/___*tfdi/___*tfsi/___float*itf,
#     ___extenddftf2, ___multc3, and the x86_64 ___cpu_model) or from the linker itself
#     (___dso_handle). A missing one fails the link, not the launch.
#   - The `$INODE64` names are the x86_64 spellings of stat/fstat/lstat; arm64 imports the plain ones.
#
# To add a name the check reports: confirm the app's minimum macOS exports it for that
# architecture (the SDK's .tbd files, or the API's availability in its header), add it in sorted
# order, and say in the commit how it was checked. One Mach-O symbol per line, as nm prints it.
