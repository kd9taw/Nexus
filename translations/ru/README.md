# Nexus на русском языке — комплект локализации

Nexus — это программа для радиолюбителей («всё в одном окне»): управление трансивером через CAT, декодирование и передача FT8, CW, SSB, RTTY, PSK, SSTV и APRS, аппаратный журнал, карта связей, споты и трекинг спутников.

Программа уже поддерживает английский, немецкий, испанский, французский и японский языки. Добавление русского языка позволит русскоязычным операторам комфортно работать в эфире на родном языке.

Перевод: loloka; дополнен и вычитан к выпуску, в котором русский язык вошёл в Nexus.

---

## Что нужно делать

Откройте файл **`nexus-ru-translation.csv`** в текстовом редакторе или табличном процессоре. Заполняйте колонку **`russian`**.

Остальные колонки изменять нельзя. Программа сопоставляет строки по колонке `key`, поэтому изменение или удаление ключа приводит к потере строки. Сохраняйте файл строго в кодировке **UTF-8**.

| Колонка | Описание |
|---|---|
| `priority` | Приоритет от 1 (самый важный интерфейс) до 6. |
| `key` | Внутренний идентификатор строки. **Не изменять.** |
| `english` | Исходный английский текст. **Не изменять.** |
| `russian` | **Ваш перевод.** |
| `do_not_translate` | Список терминов, которые должны остаться в строке без изменений. |
| `notes` | Контекстные подсказки разработчика. |

Пустые строки автоматически замещаются английским оригиналом при работе программы — ничего не ломается и не вылетает.

## Главные технические правила (что может сломать программу)

1. **Слоты подстановки параметров `{{двойные скобки}}`:**
   - Оригинал: `Imported {{count}} QSOs`
   - Перевод: `Импортировано {{count}} QSO` (или `{{count}} связей импортировано`)
   - **Запрещено:** менять название слота внутри скобок (например, `{{количество}}`) или писать одинарные скобки `{count}`.

2. **Теги форматирования `<b>` ... `</b>`:**
   - Оригинал: `<b>{{achievement}}</b> — turn on <b>{{feature}}</b>?`
   - Перевод: `<b>{{achievement}}</b> — включить <b>{{feature}}</b>?`
   - Теги должны быть парными и закрытыми.

3. **Технические числа сохраняют точку (не запятую!):**
   - `14.074`, `2.4 kHz`, `45.45 baud`.
   - В русской прозе используется запятая, но в радиолюбительских частотах и технических параметрах **всегда остается точка**. Запятая в частоте приведет к ошибке настройки трансивера.

4. **Макросы CW в одинарных фигурных скобках:**
   - `{NAME}`, `{MYCALL}`, `{RST}`, `{MYSTATE}`. Копируются точно как есть, заглавными буквами.

5. **Радиолюбительские термины:**
   - `QSO`, `CW`, `RTTY`, `FT8`, `ADIF`, `Cabrillo`, `LoTW`, `QRZ`, `POTA`, `DX`, `QSY`, `CAT` остаются на английском, как в международном эфире. См. `GLOSSARY.md`.

## Множественное число (строки `::one`, `::few`, `::many`, `::other`)

У каждого ключа с множественным числом четыре строки:
```csv
logbook.import.imported::one,Imported {{count}} QSO        → Импортирована {{count}} связь   (1, 21, 31, 101…)
logbook.import.imported::few,Imported {{count}} QSOs       → Импортировано {{count}} связи   (2–4, 22–24…)
logbook.import.imported::many,Imported {{count}} QSOs      → Импортировано {{count}} связей  (0, 5–20, 25–30…)
logbook.import.imported::other,Imported {{count}} QSOs     → то же, что ::many (дробные числа и запасной вариант)
```
Заполняйте все четыре строки. В `::few` и `::many` английский текст — это форма `other`.

Форма `::one` срабатывает не только для 1, но и для 21, 31, 101 и т. д. Поэтому в строке `::one` пишите `{{count}}`, а не «один» или цифру 1, если английская форма `other` показывает число (даже когда английская `::one` пишет «One»). `verify-ru.py` это проверяет.

## Автоматическая проверка перевода

Для проверки корректности перевода запустите встроенный скрипт:

```bash
python3 verify-ru.py nexus-ru-translation.csv
```

Скрипт проверяет, что все ключи на месте, макросы и теги не повреждены, а частоты не содержат запятых.

## Сборка каталога TypeScript

После завершения перевода сформируйте каталог `ru.ts` для самого приложения:

```bash
python3 csv-to-catalog.py nexus-ru-translation.csv -o ../../ui/src/i18n/ru.ts --splash-out splash-ru.json
```
